# 液性よみ（ekisei-yomi）

洗剤の種類と pH の数を見て、表示する液性（酸性・弱酸性・中性・弱アルカリ性・アルカリ性）を当てる1日5問の学習ゲーム。正解したら「どの側？」（酸性の側・中性・アルカリ性の側）も選ぶ。pH 3.0・6.0・8.0・11.0 ちょうどのような、まちがえやすい区切りも出る。

遊ぶ: <https://satou-aaaaa.github.io/ekisei-yomi/>

- 答えは消費者庁「雑貨工業品品質表示規程」（合成洗剤・住宅用又は家具用の洗浄剤の液性の区分）で確かめたことだけです。
- 問題の pH の数は練習のための作り話で、実在の商品の値ではありません。このゲームは教科書や消費者庁の資料の代わりではありません。くわしくは教科書や、消費者庁のホームページで確かめてください。
